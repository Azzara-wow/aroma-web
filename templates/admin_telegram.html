Как настроить (один раз):
  1. В Telegram напишите @BotFather → /newbot, получите токен.
  2. На Render добавьте переменную TELEGRAM_BOT_TOKEN = этот токен, сохраните (передеплой).
  3. Откройте своего бота в Telegram и нажмите Start (или напишите ему любое сообщение).
  4. Обновите эту страницу — ниже появится ваш chat_id.
  5. На Render добавьте TELEGRAM_CHAT_ID = этот id, сохраните.
  6. Вернитесь сюда и нажмите «Отправить тест».
